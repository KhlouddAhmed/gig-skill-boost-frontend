# GIG Skill Boost: Front-End Development

My assignments and projects from the **GIG Skill Boost Program**, Front-End Development track (React + TypeScript).

**Format:** 8 weeks, 8 modules, live sessions + recorded content
**Author:** Khloud Ahmed Mahmoud ([@KhlouddAhmed](https://github.com/KhlouddAhmed))

---

## About the Course

This track takes a learner from web basics to building and deploying a complete, responsive front-end application. It starts with HTML and CSS, moves into JavaScript, then covers React, TypeScript, forms, hooks, APIs, routing, authentication, and clean project structure. The course ends with a team project deployed to production.

## Tech Stack

- HTML5, CSS3 (Flexbox and Grid, responsive design)
- JavaScript (ES6+) and the DOM
- React
- TypeScript
- REST APIs, async data, routing, authentication
- Git and GitHub
- VS Code, Node.js and npm

